# 站点使用

## 页面结构

| 路径 | 内容 |
|---|---|
| `/` | 来源列表和每个来源的最近提交 |
| `/docs/<slug>` | 某个来源的根目录 |
| `/docs/<slug>/<path>` | 目录或文档 |
| `/admin` | 管理后台，仅管理员可见 |

地址可以直接分享和刷新，前端路由由服务端回退到 `index.html`。

## 浏览

- 首页卡片展示所有启用的来源，以及最近的提交记录。
- 点击卡片进入来源，侧栏按仓库目录树展示文档。
- 带锁图标的文档表示匿名不可见，登录后才能打开。
- 面包屑可以返回上级目录或首页。
- 页面右上角可以切换明暗主题。
- 移动端点击左上角菜单按钮展开侧栏。

## 登录与退出

点击右上角“登录账户”，跳转到 OIDC 服务完成登录。登录状态默认保持 7 天，访问令牌快到期时服务端会自动刷新。

右上角会显示当前用户名称：

- 点击用户名进入管理后台。
- 点击“退出”结束会话。

角色：

| 角色 | 能力 |
|---|---|
| `viewer` | 浏览公开文档和登录可见文档 |
| `editor` | 浏览、新建、编辑、移动、删除文档，上传图片，导入 Markdown |
| `admin` | 编辑者能力，以及管理后台 |

## 阅读文档

- 正文标题来自 front-matter 的 `title`，没有时使用文件名。
- 正文中的三级标题会生成右侧目录，点击可跳转。
- 代码块、Mermaid、数学公式由浏览器渲染。
- 私有文档右上角显示“仅登录可见”。
- 登录用户可以打开草稿，但侧栏不会额外标记草稿状态。

## 编辑文档

编辑者打开文档后会看到操作按钮：

- **编辑**：进入 Cherry Markdown 编辑器。
- **改动记录**：查看该文档最近 30 次提交和 diff。
- **移动**：输入新路径，确认后移动文件。
- **删除**：确认后删除文件。

编辑界面：

- 顶部可以修改标题。
- “匿名可读”复选框对应 front-matter 的 `public`。
- 保存快捷键为 `Ctrl+S` 或 `Cmd+S`。
- 工具栏可以插入图片，图片会先上传到 S3 再写入正文。
- 点击“取消”放弃未保存的修改。

保存采用乐观锁。如果文件在编辑期间被他人修改，会提示内容已更新，需要刷新后重新编辑。

## 新建内容

在目录页面底部有管理操作：

- **新建文档**：输入完整路径，例如 `入门/安装.md`，创建一篇带占位正文的文档。
- **新建子目录**：输入目录名，自动创建该目录下的 `README.md`。

侧栏底部的“新建文档”按钮会提示输入目录名，并创建该目录的 `README.md`。如果只想创建单篇文档，请使用目录页面的“新建文档”。

新文档会自动写入 `title` front-matter，正文默认为“输入内容...”。

## 调整顺序

编辑者把鼠标移到侧栏文档上，会出现上下箭头。点击箭头会交换同级文档顺序，并写入当前目录的 `_meta.yaml`。

目录之间的顺序不能通过界面调整，需要手动编辑对应父目录的 `_meta.yaml`，详见[文档仓库规范](content.md#排序)。

## 导入 Markdown

编辑者可以把 `.md` 文件直接拖到正文区域：

- 支持一次拖入多个文件。
- 导入到当前目录。
- 文件名重复时会失败。
- 只处理 `.md`，其他文件会被忽略。

导入完成后会提示文件数量，侧栏可能需要刷新或等待索引更新。

## 改动记录

“改动记录”面板展示当前文档的提交列表：

- 每条记录包含提交信息、作者、时间和短 SHA。
- 点击记录查看该次提交的文件 diff。
- 只有登录用户可以查看提交详情。
- 路径变更后，新路径只能看到移动之后的记录；文档删除后无法再从站点查看历史，但 Git 中仍保留提交。

## 权限不足时

- 未登录访问私有文档：显示“文档不存在”，不会暴露路径是否存在。
- 登录但角色是 `viewer`：看不到编辑、新建、移动、删除和导入入口。
- 非管理员访问 `/admin`：显示需要管理员权限。
- 登录被拒绝：联系管理员检查 `access.allowed_groups` 或 OIDC 的 `groups` 声明。

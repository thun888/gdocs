# gdocs 使用文档

gdocs 是一个把 Markdown 正文存放在 Git 仓库里的文档站。站点自身只保存用户、权限、来源和文档索引，正文与历史都在 Forgejo（Gitea 兼容）中，图片存放在 S3 兼容存储。

## 文档分类

| 分类 | 文档 | 适合谁 |
|---|---|---|
| 入门 | [快速开始](getting-started.md) | 第一次在本机跑起来 |
| 配置 | [配置参考](configuration.md) | 配置数据库、SSO、仓库和对象存储 |
| 内容 | [文档仓库规范](content.md) | 写文档、组织目录、控制可见性 |
| 使用 | [站点使用](user-guide.md) | 浏览、编辑、导入、查看历史 |
| 管理 | [管理后台](administration.md) | 管理来源、用户组、用户和站点设置 |
| 部署 | [构建与部署](deployment.md) | 构建二进制、反向代理、升级与备份 |
| 排查 | [故障排查](troubleshooting.md) | 启动、登录、仓库、上传出问题时 |

## 推荐阅读顺序

- 第一次部署：快速开始 → 配置参考 → 构建与部署
- 日常写文档：文档仓库规范 → 站点使用
- 站点管理员：管理后台 → 故障排查
- 只读用户：站点使用

## 基本约定

- 命令默认在仓库根目录执行，配置文件默认为 `config.yaml`。
- 示例中的域名、令牌、密钥都是占位符，需要替换为实际值。
- `config.yaml` 已被 `.gitignore` 忽略，不要把真实凭据提交到仓库。

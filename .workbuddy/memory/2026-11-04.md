## 正文字号调整（zdocs-go）
- 新增 `useFontScale`（步进 0.9 到 1.5，存 localStorage `gdocs-font-scale`），`PageShell` 右侧 `.side-tools` 里放了 A+ / A− 胶囊按钮，到边界自动禁用；`index.html` 的内联脚本在首屏前预置 `--font-scale`，避免闪跳。
- 为保证层级关系不变，正文排版改成 em 递进：`.article-content` 基准 `calc(1.2rem * var(--font-scale, 1))`，h1 2.33em / h2 2em / h3 1.67em / h4 1.33em / h5 1em / h6 0.83em，代码块 0.79em，行高改无单位 1.67；`.article-title` 用 `calc(3.2rem * var(--font-scale, 1))`。
- 实测 1.0 与 1.4 两档：标题 51.2→71.68、h2 38.4→53.76、p 19.2→26.88，全部严格等比例。
- 注意：用 Python 改写 CSS 会把换行变成 CRLF，改完需转回 LF 再提交。
- 依用户反馈收窄档位：`STEPS = [0.8, 0.9, 1, 1.1, 1.2, 1.3]`，最小 0.8（正文 15.36px），最大 1.3（标题 66.56px）。

## 前置代理身份认证（zdocs-go）
- 新增配置段 `proxy_auth`：`enabled`、`user_header`/`sub_header`/`email_header`/`name_header`/`groups_header`（默认 tinyauth 的 `Remote-*`）、`login_url`（支持 `{redirect}`）、`logout_url`、`cache_seconds`（默认 60）。
- 实现 `internal/auth/proxy.go`：只采信 `server.trusted_proxies` 内地址发来的身份头；`Remote-Sub` 优先作为 subject，缺失时回落到 `Remote-User`；自动建用户、按 `Remote-Groups` 同步角色，组头为空时保留库内角色并跳过 `allowed_groups`；带 64 把分段锁和 TTL 缓存。
- 代理认证优先于站点会话；无会话时 CSRF 改用 `HMAC(key, "csrf-proxy", subject)` 的无状态令牌，`/me` 下发。
- `users.subject` 由 varchar(32) 扩到 255（迁移 `00002_proxy_auth.sql`），因为 tinyauth 的 sub 可能是 UUID。
- 退出接口在配置 `logout_url` 时返回 `{redirect}`，前端跟随跳转；管理后台改组角色后调用 `InvalidateProxyCache`。
- 部署要点：nginx 用 `auth_request` 加 5 个 `proxy_set_header` 覆盖客户端同名头；gdocs 不能暴露在绕过代理的地址上。
